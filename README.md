# 📖 MrMao — 主席模拟器

> **中文：** 基于毛泽东著作（毛选四卷+文集+诗词+建国文稿+76个知识扩展）的 AI 对话系统。**6,339 个知识块**，RAG 混合检索，两阶段推理引擎（先想后说），手机端 Web 界面。和老人家聊聊历史、哲学、时政与人生。
>
> **English:** An AI-powered dialogue system based on Mao Zedong's complete works. **6,339 knowledge chunks**, hybrid RAG retrieval, two-stage reasoning engine (think→speak), mobile-friendly web UI. Chat with the Chairman about history, philosophy, politics, and life.

---

## ✨ 功能特点

### 💬 两阶段对话引擎
- **先想后说**：`think` 阶段先判断你话里的深层意图（要方法 / 求安慰 / 试探 / 闲聊……），结合知识框架与著作原文在心里想清楚；`speak` 阶段再用毛泽东的口吻自然说出
- **自然对话规则**：接话、长度随话题波动、结构自由、反问低频——像真人聊天，不说"矛盾分析法"这类术语，分析在心里不在嘴上
- **逐字打字效果**：模拟真实的交谈节奏，每句话带中括号动作描写
- **三层语境记忆**：最近 2 轮原话 + 5 轮要点摘要（含情绪）+ 全程话题主线，聊得再久也不断片

### 🧠 RAG 混合检索
- **向量语义检索** + **BM25 关键词检索**双通道，RRF 融合排序
- 从 6,339 个知识块中精准召回最相关的著作原文
- 聊天时实时引用出处（书名+日期），回答有据可查

### 🗣️ 意图判断与场景信号
- **意图判断器**：规则粗判你的情绪（正面/负面/中性）与需求（要信息/要情感/要行动），让主席知道怎么接你
- **场景信号检测**：结合当前场景氛围与你的状态，决定说话分寸（正式场合/闲谈/情绪低落的陪伴）

### 📚 445 篇著作全文
- 毛选四卷（133 篇）、毛泽东文集（186 篇）、建国以来文稿（13 篇精选）
- 毛泽东诗词全集（74 首）、讲话与谈话
- 分级目录阅读：分类 → 卷 → 篇名 → 全文

### 📍 场景系统
- 菊香书屋、丰泽园客厅、小路上、树下 **4 大场景**，切换带过场动画
- 每场景独立气氛与动作库，切换带过场动画与开场白
- 室内「🍵续茶 / 🚬递烟」，室外「💧喝水 / 🍉歇脚」

### 🎯 考考你
- 完全**主动触发**：点底部「☆找话题 → 📝 考考你」才会出题，绝不打扰对话
- 哲学 / 党史 / 历史 / 诗词 / 军事 5 类 30 题，弹窗内作答
- 答完展示题目介绍，你确认后才关闭；连对 3 / 5 / 7 题有主席的专属表扬

### 🔥 热搜
- 首页实时抓取百度热搜，自动过滤娱乐八卦，一键刷新
- 点击看**口语化简述**，点「🔗 看原文」在弹窗内直接读新闻正文（不跳转）
- 想聊热点就点「💬 和主席聊聊这个」，消息会自动带事件背景

### 📱 手机优先设计
- 底部四标签栏（首页/日志/场景/阅读），微信式输入框
- 100dvh 安全区适配刘海屏，触感反馈

### 🫁 疲劳度系统
- 35 轮后主席会犯困，显示「🟡累了」「🔴该休息了」
- 点击「🍵续茶」「🚬递烟」一键压缩对话，恢复精神

### 📋 日志面板
- 底部弹出层，分「当前会话」「历史记录」两个标签
- 自动保存每次对话，一键 AI 总结，编辑标题，删除记录

### 🎨 SVG 图标库
- 全部界面图标改为内联 SVG，零图片资源，任意分辨率下依然锐利

### 🗂️ 知识自动归类
- 新知识丢进 `新知识放这里/`，运行 `python tools/ingest_knowledge.py` 自动归类
- `.txt` → 语料库（重建向量索引）；`.md` → 框架层（重启服务即生效）

### 🔌 离线嵌入
- 嵌入模型 `BAAI/bge-small-zh-v1.5` 本地运行，无需联网
- 首次下载后即可离线构建索引

## 🚀 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env          # 编辑填入 DeepSeek API key
python run_pipeline.py         # 构建向量索引（首次 ~5 分钟）
python run_server.py           # 启动 http://localhost:8000
```

手机同 WiFi 打开 `http://你的电脑IP:8000`。

> 💡 **开机自启：** 右键 `install_service.bat` →「以管理员身份运行」，将注册为 Windows 服务，开机自动后台运行。

## 知识库编辑器（桌面应用）

双击 `知识库编辑器.bat` 打开工作流式编辑器（Tkinter，零依赖）：

- **工作流四步**：①新知识（刷新 `新知识放这里/`，自动去重+分类）→ ②待上传清单（调整合并目标/移除/预览）→ ③本次更改（新增+删除草稿汇总）→ ④同步与生效（原子落盘 → 自动判断：仅框架→重启服务；含语料→重建向量库+重启）
- **知识库页**：树形浏览框架层/语料库、只读预览、关键词检索、标记删除
- **原则**：落盘前磁盘零改动；删除为软删除（`新知识放这里/_已删除/`）；`_全文.txt`/大文件只读
- 命令行工具 `tools/ingest_knowledge.py` 与 `归并新知识.bat` 保留不变

📄 详细介绍（功能+使用说明）：见 [`知识库编辑器介绍.md`](知识库编辑器介绍.md)

全产品端到端测试（基础对话/场景/日志/首页/UI/异常场景）期间修复的 Bug：

## 🔧 2026-08-06 自然对话重构

将 NPC 从"固定句式/八股味"重构为"像真人聊天"（设计文档 `docs/superpowers/specs/2026-08-06-natural-conversation-redesign.md`）：

### 引擎升级
1. **意图判断器**（`pipeline/intent.py`）：规则粗判你的情绪（正面/负面/中性，含否定过滤）与需求（要信息/要情感/要行动，带隶属度），细分试探/求认可/求安慰等场景——主席先懂你，再开口
2. **自然对话规则**（手册 v5，`docs/superpowers/specs/2026-08-06-natural-conversation-redesign.md`）：接话、长度随话题波动、结构自由、反问低频、情感先行、不搬分析术语——分析在心里不在嘴上
3. **三层语境记忆**：最近 2 轮原话 + 5 轮要点摘要（含情绪）+ 全程话题主线（`pipeline/topic_thread.py`），长对话不断片
4. **场景信号检测**：结合场景氛围与你的状态（正式/闲谈/情绪低落）决定说话分寸
5. **长期记忆持久化**：会话重启后恢复三层记忆

### 机制调整
6. **考考你**：改为完全主动触发（「☆找话题 → 📝 考考你」），弹窗内作答+题目介绍+确认关闭，绝不自动打扰
7. **热搜**：口语化简述 + 「🔗 看原文」弹窗内读新闻正文；发起对话自动带事件背景
8. **冷场挂起**：进场景后先静默，不立刻搭话；场景建议独立计时
