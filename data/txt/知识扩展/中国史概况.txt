============================================================
                    中国史概况
============================================================

【远古时期】

一、旧石器时代（约170万年前-1万年前）
1. 元谋人（约170万年前）：中国境内最早的人类化石
2. 北京人（约70万-20万年前）：使用火、打制石器
3. 山顶洞人（约3万年前）：晚期智人，出现原始宗教

二、新石器时代（约1万年前-公元前2000年）
1. 仰韶文化（约公元前5000-3000年）：彩陶、定居农业
2. 龙山文化（约公元前3000-2000年）：黑陶、城邦遗址
3. 良渚文化（约公元前3300-2200年）：玉器、水利工程

三、传说时代
1. 三皇五帝：伏羲、神农、黄帝、颛顼、帝喾、尧、舜、禹
2. 大禹治水：传说中治理洪水的英雄
3. 禅让制：原始社会末期的首领更替制度

【夏商周三代】

一、夏朝（约公元前2070-1600年）
1. 建立者：启（禹之子）
2. 标志：世袭制代替禅让制
3. 灭亡：桀暴虐无道，被商汤所灭

二、商朝（约公元前1600-1046年）
1. 建立者：汤
2. 特点：青铜文明发达、甲骨文、人祭制度
3. 盘庚迁殷：商朝稳定发展的转折点
4. 灭亡：纣王荒淫暴虐，被周武王所灭

三、西周（公元前1046-771年）
1. 建立者：周武王姬发
2. 制度创新：
   - 分封制：封诸侯，建藩屏
   - 宗法制：嫡长子继承制
   - 礼乐制度：维护社会秩序
3. 成康之治：西周鼎盛时期
4. 国人暴动：公元前841年，中国历史上第一次群众暴动
5. 灭亡：犬戎入侵，周幽王被杀

四、东周（公元前770-256年）
1. 平王东迁洛邑，史称东周
2. 春秋时期（公元前770-476年）：
   - 五霸争雄：齐桓公、晋文公、楚庄王、吴王阖闾、越王勾践
   - 管仲改革：齐国称霸的基础
   - 初税亩：鲁国承认土地私有
   - 百家争鸣开端
3. 战国时期（公元前475-221年）：
   - 七雄并立：齐、楚、燕、韩、赵、魏、秦
   - 变法运动：商鞅变法（秦国）、李悝变法（魏国）、吴起变法（楚国）
   - 百家争鸣高潮
   - 长平之战（公元前260年）：秦赵决战，赵国惨败

【秦汉时期】

一、秦朝（公元前221-206年）
1. 统一六国：秦始皇嬴政（公元前221年）
2. 制度创新：
   - 中央集权：皇帝制度、三公九卿
   - 郡县制：取代分封制
   - 统一文字、货币、度量衡
   - 修筑长城、驰道
3. 焚书坑儒（公元前213年）
4. 二世而亡：陈胜吴广起义（公元前209年），刘邦项羽争霸

二、西汉（公元前202-公元8年）
1. 建立者：刘邦（汉高祖）
2. 文景之治：文帝刘恒、景帝刘启，休养生息
3. 汉武帝盛世（公元前141-87年）：
   - 罢黜百家，独尊儒术
   - 推恩令：削弱诸侯王势力
   - 北击匈奴：卫青、霍去病
   - 张骞出使西域
4. 王莽改制（公元8年）：托古改制，引发绿林赤眉起义

三、东汉（公元25-220年）
1. 建立者：刘秀（光武帝）
2. 光武中兴
3. 外戚宦官交替专权
4. 黄巾起义（公元184年）：张角领导，动摇东汉根基
5. 三国鼎立局面形成

【魏晋南北朝】

一、三国时期（220-280年）
1. 曹魏（220-265年）：曹操、曹丕建立
2. 蜀汉（221-263年）：刘备建立
3. 东吴（222-280年）：孙权建立
4. 赤壁之战（208年）：孙刘联军击败曹操
5. 司马炎篡魏建晋（265年）

二、西晋（265-316年）
1. 建立者：司马炎（晋武帝）
2. 太康之治：短暂繁荣
3. 八王之乱（291-306年）：宗室混战，国力衰竭
4. 五胡乱华：匈奴、鲜卑、羯、氐、羌等少数民族南下
5. 永嘉之乱（316年）：西晋灭亡

三、东晋十六国（317-420年）
1. 东晋建立：司马睿南渡建康（南京）
2. 淝水之战（383年）：东晋以少胜多击败前秦苻坚
3. 南朝更迭：宋、齐、梁、陈
4. 北朝变迁：北魏统一北方，后分裂为东魏、西魏

四、南北朝（420-589年）
1. 北魏孝文帝改革（486年）：
   - 迁都洛阳
   - 推行汉化政策
   - 均田制
2. 佛教兴盛：石窟艺术（龙门、云冈）
3. 科技成就：祖冲之算圆周率、贾思勰《齐民要术》

【隋唐五代】

一、隋朝（581-618年）
1. 建立者：杨坚（隋文帝）
2. 统一全国（589年）：灭陈朝
3. 制度创新：
   - 三省六部制
   - 科举制：打破门阀垄断
   - 均田制、租庸调制
4. 大运河开凿：贯通南北
5. 炀帝暴政：三征高丽、大兴土木
6. 灭亡：瓦岗军起义，李渊太原起兵

二、唐朝（618-907年）
1. 建立者：李渊（唐高祖）
2. 贞观之治（627-649年）：唐太宗李世民
   - 虚怀纳谏（魏徵）
   - 轻徭薄赋
   - 完善科举
3. 武则天时期（690-705年）：唯一女皇帝
4. 开元盛世（713-741年）：唐玄宗李隆基
   - 姚崇、宋璟为相
   - 经济文化繁荣
5. 安史之乱（755-763年）：
   - 安禄山、史思明叛乱
   - 唐朝由盛转衰
6. 藩镇割据：节度使权力膨胀
7. 黄巢起义（875-884年）：冲天大将军
8. 朱温篡唐（907年）：五代十国开始

三、五代十国（907-979年）
1. 五代：后梁、后唐、后晋、后汉、后周（中原地区）
2. 十国：吴、南唐、吴越、楚、闽、南汉、前蜀、后蜀、荆南、北汉
3. 后周世宗柴荣改革：为北宋统一奠定基础

【宋辽金元】

一、北宋（960-1127年）
1. 建立者：赵匡胤（宋太祖）
2. 杯酒释兵权：加强中央集权
3. 重文轻武政策
4. 王安石变法（1069-1085年）：
   - 青苗法、募役法、方田均税法
   - 遭到保守派反对
5. 澶渊之盟（1005年）：与辽议和
6. 靖康之耻（1127年）：金兵俘虏徽钦二帝

二、南宋（1127-1279年）
1. 建立者：赵构（宋高宗）
2. 岳飞抗金：郾城大捷
3. 绍兴和议（1141年）：杀岳飞，向金称臣
4. 理学兴起：朱熹、程颢程颐
5. 经济繁荣：江南开发、海外贸易
6. 灭亡：崖山海战，陆秀夫背幼帝跳海

三、辽朝（907-1125年）
1. 建立者：耶律阿保机
2. 契丹族政权
3. 耶律楚材：促进汉化
4. 被金所灭

四、金朝（1115-1234年）
1. 建立者：完颜阿骨打
2. 女真族政权
3. 灭辽、灭北宋
4. 被蒙古所灭

五、元朝（1271-1368年）
1. 建立者：忽必烈（元世祖）
2. 统一全国（1279年）：灭南宋
3. 制度特点：
   - 行省制：现代省级行政区划的雏形
   - 民族等级：蒙古人、色目人、汉人、南人
4. 科技成就：郭守敬《授时历》、火药应用
5. 红巾军起义（1351年）：刘福通、朱元璋
6. 灭亡：朱元璋攻克大都（1368年）

【明清时期】

一、明朝（1368-1644年）
1. 建立者：朱元璋（明太祖）
2. 制度变革：
   - 废除丞相，设内阁
   - 特务机构：锦衣卫、东厂
   - 八股取士
3. 永乐盛世（1403-1424年）：朱棣
   - 迁都北京
   - 郑和下西洋（1405-1433年）
   - 编纂《永乐大典》
4. 土木堡之变（1449年）：英宗被俘
5. 张居正改革（1572-1582年）：一条鞭法
6. 万历怠政：后期衰落
7. 李自成起义（1628-1644年）：
   - 提出"均田免粮"
   - 攻克北京（1644年）
8. 崇祯帝自缢：明朝灭亡

二、清朝前期（1644-1840年）
1. 入关（1644年）：顺治帝
2. 康雍乾盛世：
   - 康熙帝（1661-1722年）：平定三藩、收复台湾、抗击沙俄
   - 雍正帝（1723-1735年）：摊丁入亩、改土归流、设立军机处
   - 乾隆帝（1736-1795年）：十全武功、编纂《四库全书》
3. 疆域奠定：奠定现代中国版图基础
4. 人口增长：突破三亿

三、清朝后期（1840-1912年）
1. 鸦片战争（1840-1842年）：
   - 签订《南京条约》
   - 中国开始沦为半殖民地半封建社会
2. 太平天国运动（1851-1864年）：
   - 洪秀全领导
   - 《天朝田亩制度》
   - 曾国藩湘军镇压
3. 洋务运动（1861-1894年）：
   - 自强求富
   - 创办近代企业、新式学堂
4. 甲午战争（1894-1895年）：
   - 签订《马关条约》
   - 康有为梁启超维新变法
5. 戊戌变法（1898年）：光绪帝支持，慈禧太后镇压
6. 义和团运动（1899-1901年）：扶清灭洋
7. 八国联军侵华（1900年）：签订《辛丑条约》
8. 辛亥革命（1911年）：武昌起义，各省响应
9. 宣统退位（1912年2月12日）：清朝灭亡

【中华民国时期】

一、北洋政府时期（1912-1928年）
1. 中华民国成立（1912年1月1日）：孙中山就任临时大总统
2. 袁世凯就任大总统（1912年3月）
3. 二次革命（1913年）：孙中山反对袁世凯
4. 袁世凯复辟帝制（1915-1916年）：护国运动
5. 张勋复辟（1917年）：段祺瑞讨逆
6. 护法运动（1917-1922年）：孙中山南下广州
7. 五四运动（1919年5月4日）：新文化运动
8. 中国共产党成立（1921年7月）
9. 第一次国共合作（1924-1927年）
10. 北伐战争（1926-1928年）：蒋介石领导

二、南京国民政府时期（1927-1949年）
1. 四一二政变（1927年4月12日）：蒋介石清党
2. 南昌起义（1927年8月1日）：中国共产党建军
3. 秋收起义（1927年9月）：毛泽东领导
4. 井冈山会师（1928年4月）：朱毛红军
5. 九一八事变（1931年9月18日）：日本侵占东北
6. 长征（1934-1935年）：战略转移
7. 西安事变（1936年12月12日）：张学良杨虎城逼蒋抗日
8. 全面抗战（1937-1945年）：
   - 卢沟桥事变（1937年7月7日）
   - 南京大屠杀（1937年12月）
   - 台儿庄战役（1938年）
   - 百团大战（1940年）
   - 抗战胜利（1945年8月15日）
9. 解放战争（1946-1949年）：
   - 三大战役：辽沈、淮海、平津
   - 渡江战役（1949年4月）
   - 中华人民共和国成立（1949年10月1日）

【中华人民共和国时期】

一、建国初期（1949-1956年）
1. 土地改革（1950-1952年）
2. 抗美援朝（1950-1953年）
3. 三大改造（1953-1956年）：农业、手工业、资本主义工商业
4. 一五计划（1953-1957年）：工业化起步
5. 社会主义制度确立（1956年）

二、探索时期（1956-1966年）
1. 中共八大（1956年）：正确分析国内主要矛盾
2. 大跃进（1958-1960年）：总路线、人民公社
3. 庐山会议（1959年）：彭德怀问题
4. 调整恢复（1961-1965年）：八字方针

三、文革时期（1966-1976年）
1. 五一六通知（1966年5月）
2. 红卫兵运动
3. 九一三事件（1971年）：林彪叛逃
4. 周恩来逝世（1976年1月8日）
5. 四五运动（1976年4月5日）
6. 粉碎四人帮（1976年10月6日）

四、改革开放时期（1978年至今）
1. 十一届三中全会（1978年12月）：拨乱反正
2. 家庭联产承包责任制（1978年起）
3. 经济特区设立（1980年）：深圳、珠海、汕头、厦门
4. 城市经济体制改革（1984年）
5. 对外开放格局形成
6. 邓小平南巡讲话（1992年）
7. 社会主义市场经济体制确立（1992年）
8. 香港回归（1997年7月1日）
9. 澳门回归（1999年12月20日）
10. 加入WTO（2001年12月）
11. 科学发展观（2003年）
12. 中国梦（2012年）：中华民族伟大复兴
13. 新时代中国特色社会主义（2017年）
