【第一章 唯物史观】

一、历史唯物主义的基本原理

1. 社会存在决定社会意识

马克思在《政治经济学批判》序言中阐述了唯物史观的核心思想：

"人们在自己生活的社会生产中发生一定的、必然的、不以他们的意志为转移的关系，即同他们的物质生产力的一定发展阶段相适合的生产关系。这些生产关系的总和构成社会的经济结构，即有法律的和政治的上层建筑竖立其上并有一定的社会意识形式与之相适应的现实基础。"

这一论断包含以下要点：
- 物质生产力是社会的最终决定力量
- 生产关系必须与生产力发展水平相适应
- 经济基础决定上层建筑
- 社会意识是社会存在的反映

2. 生产力与生产关系的辩证关系

生产力：
- 内容：劳动者、劳动资料（工具）、劳动对象
- 劳动者是生产力中最活跃的因素
- 科学技术是第一生产力
- 生产力的发展是社会进步的根本动力

生产关系：
- 生产资料所有制形式（最基本、最决定性的方面）
- 人们在生产中的地位和相互关系
- 产品分配形式

辩证关系：
- 生产力决定生产关系：生产力的状况决定生产关系的性质；生产力的发展决定生产关系的变革
- 生产关系反作用于生产力：适合时促进，不适合时阻碍
- 生产关系一定要适合生产力状况的规律是人类社会发展的普遍规律

3. 经济基础与上层建筑

经济基础：由社会一定发展阶段的生产力所决定的生产关系的总和。

上层建筑：
- 政治上层建筑：国家机器、政治法律制度、军队、警察、法庭、监狱等
- 观念上层建筑：政治思想、法律思想、道德、艺术、宗教、哲学等

辩证关系：
- 经济基础决定上层建筑的产生、性质和发展变化
- 上层建筑反作用于经济基础：为自己的经济基础服务，促进或阻碍其发展
- 上层建筑具有相对独立性：与社会存在发展的不完全同步性、历史继承性、内部各种形式之间的相互影响

4. 社会形态及其更替

五种社会形态：
- 原始社会：生产资料公有制，无阶级
- 奴隶社会：奴隶主占有生产资料和奴隶
- 封建社会：地主占有土地，剥削农民
- 资本主义社会：资本家占有生产资料，剥削雇佣工人
- 共产主义社会（含社会主义初级阶段）：生产资料公有制

社会形态更替的客观必然性：
- 社会基本矛盾运动的结果
- 不以人的意志为转移
- 统一性与多样性的统一
- 前进性与曲折性的统一

5. 阶级斗争理论

阶级的产生：
- 原始社会末期生产力发展的结果
- 剩余产品的出现使剥削成为可能
- 私有制的确立使阶级分化固定化

阶级斗争的作用：
- 阶级社会发展的直接动力
- 从奴隶社会到资本主义社会，阶级斗争推动社会形态更替
- "至今一切社会的历史都是阶级斗争的历史"（《共产党宣言》）

阶级分析方法：
- 运用马克思主义的阶级观点分析社会现象
- 认清社会各阶级的经济地位和政治态度
- 区分敌我友
- 在社会主义时期正确处理人民内部矛盾

【第二章 剩余价值理论】

一、劳动价值论

1. 商品的二因素：
- 使用价值：商品能满足人们某种需要的属性，是商品的自然属性
- 价值：凝结在商品中的无差别的人类劳动，是商品的社会属性
- 使用价值和价值的对立统一构成商品

2. 劳动的二重性：
- 具体劳动：在一定的具体形式下进行的劳动，创造使用价值
- 抽象劳动：撇开具体形式的无差别的人类劳动，形成价值
- 具体劳动和抽象劳动不是两次劳动，而是同一劳动的两个方面

3. 价值量：
- 由社会必要劳动时间决定，不是由个别劳动时间决定
- 社会必要劳动时间：在现有的社会正常的生产条件下，在社会平均的劳动熟练程度和劳动强度下制造某种使用价值所需要的劳动时间
- 价值量与劳动生产率成反比

4. 价值形式的发展：
- 简单的或偶然的价值形式：1件上衣 = 20码麻布
- 总和的或扩大的价值形式：1件上衣 = 20码麻布 = 10磅茶叶 = ...
- 一般价值形式：20码麻布 = 1件上衣，10磅茶叶 = 1件上衣，...
- 货币形式：一切商品都用货币来表现自己的价值

5. 货币的职能：
- 价值尺度：衡量商品价值
- 流通手段：充当交换媒介
- 贮藏手段：退出流通被保存
- 支付手段：清偿债务、纳税等
- 世界货币：在国际市场上使用

6. 价值规律：
- 商品的价值量由社会必要劳动时间决定
- 商品交换以价值量为基础实行等价交换
- 价格围绕价值上下波动
- 价值规律的作用：调节生产、刺激技术进步、导致贫富分化

二、剩余价值的生产

1. 货币转化为资本：
- 资本的总公式：G—W—G'（货币—商品—更多的货币）
- G' = G + ΔG，其中ΔG就是剩余价值
- 剩余价值不能在流通中产生，又不能不在流通中产生
- 解决矛盾的前提：劳动力成为商品

2. 劳动力商品：
- 劳动力成为商品的两个条件：劳动者有人身自由；劳动者一无所有
- 劳动力的价值：维持劳动者生存和再生产所需的费用
- 劳动力的使用价值：能创造比自身价值更大的价值——这是剩余价值的源泉

3. 剩余价值的生产过程：
- 劳动过程：劳动者运用劳动工具作用于劳动对象，创造使用价值
- 价值增殖过程：超过劳动力价值的那部分价值形成过程
- 必要劳动时间：再生产劳动力价值的时间
- 剩余劳动时间：创造剩余价值的时间
- 剩余价值（m）：由雇佣工人创造的被资本家无偿占有的超过劳动力价值的价值

4. 剩余价值率：
- m' = m/v = 剩余劳动/必要劳动
- 反映资本家对工人的剥削程度

5. 两种剩余价值生产方法：

绝对剩余价值：
- 在必要劳动时间不变的条件下，通过延长工作日长度而生产
- 工作日的界限：生理界限（吃饭睡觉等）和社会道德界限（文化教育等）
- 早期资本主义普遍采用：14-16小时工作日

相对剩余价值：
- 在工作日长度不变的条件下，通过缩短必要劳动时间而生产
- 必要劳动时间的缩短需要提高劳动生产率
- 降低生活资料价值→降低劳动力价值→缩短必要劳动时间
- 超额剩余价值：个别资本家率先提高生产率获得的额外收益
- 超额剩余价值是相对剩余价值的起点

6. 剩余价值规律是资本主义生产方式的绝对规律：
- 资本主义生产的目的是追求剩余价值
- 一切资本主义经济活动都围绕这一目的展开

三、资本积累

1. 简单再生产与扩大再生产：
- 简单再生产：剩余价值全部用于消费，生产在原有规模重复
- 扩大再生产：剩余价值的一部分转化为资本，生产规模扩大
- 资本积累：剩余价值转化为资本的过程

2. 资本构成：
- 资本技术构成：生产资料与劳动力的物质比例
- 资本价值构成：不变资本与可变资本的比例（c:v）
- 资本有机构成：由技术构成决定并反映技术构成变化的价值构成

3. 资本积累的一般规律：
- 资本有机构成不断提高：不变资本比重增大
- 相对过剩人口：劳动力供给超过资本需求
- 贫富两极分化：一极是财富积累，一极是贫困积累
- 无产阶级贫困化：相对贫困化（收入占比下降）和绝对贫困化（生活恶化）

4. 资本主义积累的历史趋势：
- 资本原始积累：用暴力手段剥夺小生产者
- 资本集中：大资本吞并小资本
- 资本主义基本矛盾激化：生产社会化与生产资料私人占有的矛盾
- "剥夺者被剥夺"——资本主义必然灭亡

【第三章 异化劳动理论】

一、异化劳动的四个规定

马克思在《1844年经济学哲学手稿》中提出：

1. 劳动者同劳动产品的异化：
- 工人生产的产品不归工人所有
- 工人生产的产品越多，他自身越贬值
- "工人在自己的产品中外化了自己"
- 产品成为与工人对立的异己力量

2. 劳动者同劳动活动的异化：
- 劳动不是自愿的而是被迫的
- 劳动不是满足劳动需要而是满足劳动需要以外的需要
- 工人在劳动中否定自己而不是肯定自己
- 工人感觉自己是动物而不是人

3. 劳动者同自己的类本质相异化：
- 人与动物的区别在于自由自觉的活动
- 异化劳动把这种自由自觉的活动变成了维持生存的手段
- 人的类本质被剥夺，人降为动物水平

4. 人与人相异化：
- 前三种异化的直接结果
- 人与人的关系变成敌对关系
- 每个人都从他人的异化中确认自己的异化

二、异化的根源与扬弃

1. 异化的根源：
- 私有制是异化劳动的原因也是其结果
- 分工的发展加剧了异化
- 资本主义制度下异化达到顶点

2. 异化的扬弃：
- 共产主义是扬弃私有财产的积极表现
- "共产主义是私有财产即人的自我异化的积极的扬弃"
- 不是消灭个人财产，而是消灭私有制剥削关系
- 人的本质的真正占有，向完整的人的复归

三、异化理论的意义

1. 哲学意义：
- 从哲学角度批判资本主义
- 丰富了对人的本质的理解
- 为历史唯物主义奠定基础

2. 理论发展：
- 早期马克思的思想核心
- 后期转向经济学批判但异化思想贯穿始终
- 《资本论》中的"商品拜物教"是异化理论的深化

【第四章 商品拜物教】

一、商品拜物教的含义

马克思在《资本论》第一卷第一章中提出：

"商品形式的奥秘不过在于：商品形式在人们面前把人们本身劳动的社会性质反映成劳动产品本身的物的性质，反映成这些物的天然的社会属性，从而把生产者同总劳动的社会关系反映成存在于生产者之外的物与物之间的社会关系。"

二、拜物教的三种形式

1. 商品拜物教：
- 商品的价值看起来像是商品本身的自然属性
- 人与人之间的社会关系被物的关系所掩盖
- 人们崇拜商品，忘记了它是人类劳动的产物

2. 货币拜物教：
- 货币作为一般等价物，具有了神奇的力量
- "金钱万能"的观念
- 货币似乎自身具有增殖能力

3. 资本拜物教：
- 资本似乎自身就能带来利润
- "钱生钱"的表象
- 掩盖了剩余价值来源于工人的剩余劳动这一真相

三、拜物教的批判

1. 揭示了资本主义社会的物化现象：
- 人与人的关系变成了物与物的关系
- 人的社会关系被物的关系所取代
- 人受自己创造的物的支配

2. 对当代社会的启示：
- 消费主义盛行：人们通过消费定义自我
- 商品逻辑渗透一切领域：文化、教育、医疗
- 人的价值被市场价值取代
- 异化现象以新的形式存在：数字异化、算法异化

【第五章 资本主义基本矛盾】

一、基本矛盾的内容

生产社会化与生产资料资本主义私人占有之间的矛盾。

表现：
1. 生产社会化的发展：
   - 生产过程社会化：分工协作日益精细
   - 产品社会化：产品是许多人共同劳动的结果
   - 生产资料社会化：大规模生产需要集中使用
   - 市场社会化：国内市场和国际市场形成

2. 生产资料私人占有：
   - 生产资料归资本家私人所有
   - 生产成果归资本家支配
   - 生产决策以私人利润为目的

二、基本矛盾的具体表现

1. 个别企业生产的有组织性与整个社会生产的无政府状态之间的矛盾：
   - 每个企业内部严密组织
   - 整个社会生产盲目竞争
   - 比例失调导致经济危机

2. 生产无限扩大的趋势与劳动人民有支付能力的需求相对缩小之间的矛盾：
   - 资本家追求利润最大化，不断扩大生产
   - 工人被剥削，购买力相对下降
   - 生产过剩导致危机

三、经济危机

1. 实质：生产相对过剩的危机
   - 不是绝对过剩（人民需要但买不起）
   - 而是相对过剩（相对于有支付能力的需求）

2. 根源：资本主义基本矛盾

3. 周期性：危机→萧条→复苏→高涨→危机
   - 固定资本更新是周期性的物质基础

4. 战后新特点：
   - 危机频率增加
   - 滞胀出现
   - 金融危机突出
   - 全球化加速危机传导

【第六章 共产主义理论】

一、共产主义社会的发展阶段

1. 共产主义社会第一阶段（社会主义社会）：
- 生产资料公有制
- 按劳分配："各尽所能，按劳分配"
- 仍存在资产阶级法权（事实上的不平等）
- 国家还未消亡

2. 共产主义社会高级阶段：
- "迫使个人奴隶般地服从分工的情形已经消失"
- 脑力劳动和体力劳动的对立消失
- 劳动成为生活的第一需要
- "各尽所能，按需分配"
- 国家自行消亡

二、共产主义的本质

1. 人的解放：
- 从剥削制度下解放
- 从异化劳动中解放
- 从旧式分工中解放
- 实现人的自由全面发展

2. 自由王国：
- "自由王国只是在由必需和外在目的规定要做的劳动终止的地方才开始"
- 人从必然王国走向自由王国
- 真正成为自然界、社会和自身的主人

三、实现共产主义的条件

1. 生产力高度发展：
- 物质财富极大丰富
- "集体财富的一切源泉都充分涌流"

2. 生产关系变革：
- 消灭私有制
- 建立公有制
- 消灭阶级差别

3. 精神条件：
- 人的思想觉悟极大提高
- 劳动成为生活第一需要
- 科学文化高度发达

4. 国际条件：
- 共产主义是国际性事业
- "全世界无产者，联合起来！"

【第七章 马克思主义的方法论】

一、辩证法

1. 唯物辩证法的基本规律：
- 对立统一规律：事物发展的根本动力
- 质量互变规律：量变到质变的转化
- 否定之否定规律：螺旋式上升发展

2. 唯物辩证法的范畴：
- 原因和结果
- 必然性和偶然性
- 可能性和现实性
- 内容和形式
- 本质和现象
- 全局和局部

二、认识论

1. 实践观点：
- 实践是认识的来源
- 实践是认识发展的动力
- 实践是检验真理的唯一标准
- 实践是认识的目的

2. 认识的辩证过程：
- 从感性认识到理性认识
- 从理性认识回到实践
- 实践→认识→再实践→再认识，循环往复

3. 真理观：
- 真理的客观性
- 真理的绝对性和相对性
- 实践是检验真理的唯一标准

三、历史唯物主义方法论

1. 实事求是：
- 从实际出发
- 尊重客观规律
- 主观与客观统一

2. 矛盾分析法：
- 一分为二看问题
- 具体问题具体分析
- 把握主要矛盾和次要矛盾

3. 阶级分析法：
- 在阶级社会中分析阶级关系
- 认清阶级本质和阶级利益

4. 群众路线：
- 一切为了群众
- 一切依靠群众
- 从群众中来，到群众中去

【第八章 马克思主义的历史地位与当代价值】

一、历史地位

1. 哲学革命：
- 实现了从唯心主义到唯物主义的转变
- 实现了从形而上学到辩证法的转变
- 实现了从解释世界到改变世界的转变

2. 科学社会主义的奠基：
- 使社会主义从空想变为科学
- 揭示了资本主义灭亡和共产主义胜利的必然性
- 指出了无产阶级的历史使命

3. 对人类思想的影响：
- 成为世界工人运动的指导思想
- 影响了20世纪世界格局
- 至今仍是最有影响力的社会理论之一

二、当代价值

1. 分析当代资本主义：
- 金融危机印证了基本矛盾理论
- 贫富分化验证了资本积累规律
- 全球化体现了生产社会化趋势
