============================================================
                  西方历史概要
============================================================

【第一章 古希腊文明（约公元前2000-前146年）】

一、米诺斯文明（约公元前2000-前1450年）
1. 发源地：克里特岛
2. 特点：海上贸易发达，宫殿文化繁荣
3. 克诺索斯宫殿：迷宫传说的原型
4. 线形文字A：至今未被完全破译
5. 衰落原因：火山爆发、地震、迈锡尼入侵

二、迈锡尼文明（约公元前1600-前1100年）
1. 发源地：伯罗奔尼撒半岛
2. 特点：尚武好战，城邦防御坚固
3. 线形文字B：已破译，为早期希腊语
4. 特洛伊战争：约公元前1200年，荷马史诗的历史原型
5. 衰落原因：海上民族入侵、内部战乱

三、黑暗时代（约公元前1100-前800年）
1. 文字失传，宫殿被毁
2. 人口减少，贸易中断
3. 口头传唱传统：荷马史诗在此期间形成
4. 社会组织：部落和氏族

四、古风时代（约公元前800-前500年）
1. 城邦兴起：
   - 雅典：民主政体的发源地
   - 斯巴达：军事化城邦
   - 科林斯：商业城邦
   - 米利都：哲学发源地

2. 殖民运动：
   - 向西：南意大利、西西里
   - 向东：小亚细亚沿岸
   - 向北：黑海沿岸

3. 重装步兵改革：公民兵取代贵族骑兵，推动民主化

4. 僭主政治：多处城邦经历僭主统治

5. 文化成就：
   - 荷马史诗：《伊利亚特》《奥德赛》
   - 赫西俄德：《神谱》《工作与时日》
   - 抒情诗：萨福、品达
   - 哲学开端：泰勒斯、阿那克西曼德、毕达哥拉斯

五、古典时代（公元前500-前323年）

1. 希波战争（前499-前449年）：
   - 马拉松战役（前490年）：雅典以少胜多
   - 温泉关战役（前480年）：斯巴达三百勇士
   - 萨拉米斯海战（前480年）：希腊舰队大败波斯
   - 普拉提亚战役（前479年）：彻底击退波斯

2. 雅典黄金时代（前461-前429年）：
   - 伯里克利执政
   - 民主制度完善：公民大会、五百人会议、陪审法庭
   - 帕台农神庙建造
   - 文化繁荣：悲剧、喜剧、哲学、历史学
   - 苏格拉底、柏拉图活跃

3. 伯罗奔尼撒战争（前431-前404年）：
   - 雅典帝国 vs 伯罗奔尼撒同盟
   - 修昔底德记录战争
   - 雅典战败，民主制衰落

4. 马其顿崛起：
   - 腓力二世统一希腊（前338年喀罗尼亚战役）
   - 亚历山大大帝东征（前334-前323年）
     * 格拉尼库斯河战役
     * 伊苏斯战役
     * 高加米拉战役
     * 征服波斯、埃及、中亚
     * 到达印度河流域

六、希腊化时代（前323-前146年）
1. 亚历山大帝国分裂为三大王国：
   - 托勒密王朝：埃及
   - 塞琉古王朝：西亚
   - 安提柯王朝：马其顿

2. 文化成就：
   - 亚历山大图书馆
   - 欧几里得《几何原本》
   - 阿基米德力学发现
   - 斯多葛学派、伊壁鸠鲁学派

3. 罗马征服：前146年科林斯陷落，希腊沦为罗马行省

【第二章 古罗马文明（公元前753-公元476年）】

一、王政时代（前753-前509年）
1. 罗慕路斯建城传说
2. 七王统治
3. 社会结构：贵族（patricians）与平民（plebeians）
4. 元老院制度起源

二、共和国时期（前509-前27年）

1. 共国制度：
   - 执政官：两人，一年一任
   - 元老院：立法咨询
   - 公民大会：选举立法
   - 保民官：保护平民权利

2. 平民斗争：
   - 保民官设立（前494年）
   - 十二铜表法（前451年）：罗马法起源
   - 李锡尼法（前367年）：平贵通婚、债务限制

3. 对外扩张：
   - 布匿战争（前264-前146年）：
     * 第一次（前264-前241年）：争夺西西里
     * 第二次（前218-前201年）：汉尼拔翻越阿尔卑斯山，坎尼战役，扎马战役
     * 第三次（前149-前146年）：迦太基被毁
   - 马其顿战争：控制希腊
   - 叙利亚战争：控制小亚细亚

4. 共和国危机：
   - 格拉古兄弟改革（前133-前121年）：土地分配
   - 马略军事改革：职业军队
   - 社会战争（前91-前88年）：意大利同盟者争取公民权
   - 斯巴达克起义（前73-前71年）：奴隶大起义
   - 前三头同盟：恺撒、庞培、克拉苏
   - 恺撒独裁（前49-前44年）：渡过卢比孔河，高卢战争，被刺杀
   - 后三头同盟：屋大维、安东尼、雷必达

三、帝国时期（前27-公元476年）

1. 奥古斯都时代（前27-公元14年）：
   - 屋大维获"奥古斯都"称号
   - 元首制：披着共和外衣的帝制
   - 罗马和平（Pax Romana）开始
   - 文化黄金时代：维吉尔、贺拉斯、奥维德

2. 朱里亚·克劳狄王朝（前27-公元68年）：
   - 提比略、卡里古拉、克劳狄、尼禄
   - 暴君频出，基督教开始传播

3. 弗拉维王朝（69-96年）：
   - 韦帕芗、提图斯、图密善
   - 圆形竞技场（斗兽场）建造

4. 五贤帝时代（96-180年）：
   - 涅尔瓦、图拉真、哈德良、安东尼·皮乌斯、马可·奥勒留
   - 帝国版图最大：从不列颠到美索不达米亚
   - 罗马法发展：《查士丁尼法典》基础

5. 三世纪危机（235-284年）：
   - 外患：蛮族入侵
   - 内乱：军人皇帝频繁更替
   - 经济崩溃：通货膨胀

6. 戴克里先改革（284-305年）：
   - 四帝共治
   - 行政改革
   - 价格管制
   - 迫害基督教

7. 君士坦丁大帝（306-337年）：
   - 米兰敕令（313年）：基督教合法化
   - 迁都君士坦丁堡（330年）
   - 尼西亚会议（325年）：统一教义

8. 帝国分裂与灭亡：
   - 狄奥多西一世（379-395年）：基督教为国教，死后帝国分裂
   - 西罗马帝国：476年灭亡
   - 东罗马帝国（拜占庭）：延续至1453年

【第三章 中世纪（约476-1453年）】

一、拜占庭帝国（395-1453年）
1. 查士丁尼一世（527-565年）：
   - 修复罗马法：《查士丁尼法典》
   - 圣索菲亚大教堂
   - 收复西部领土
2. 圣像破坏运动（726-843年）
3. 马其顿王朝复兴（867-1056年）
4. 十字军东征的冲击
5. 1453年君士坦丁堡陷落

二、伊斯兰文明兴起
1. 穆罕默德（570-632年）创立伊斯兰教
2. 四大哈里发时期（632-661年）
3. 倭马亚王朝（661-750年）：版图从西班牙到印度
4. 阿拔斯王朝（750-1258年）：
   - 巴格达成为文化中心
   - 翻译运动：保存希腊典籍
   - 数学：代数学、阿拉伯数字
   - 医学：伊本·西那《医典》
  . 法蒂玛王朝与科尔多瓦哈里发

三、西欧封建社会

1. 墨洛温王朝（481-751年）：
   - 克洛维一世统一法兰克
   - 皈依基督教

2. 加洛林王朝（751-987年）：
   - 查理曼大帝（768-814年）：
     * 统一西欧
     * 加洛林文艺复兴
     * 800年加冕为罗马皇帝
   - 凡尔登条约（843年）：三分帝国（法、德、意雏形）

3. 封建制度：
   - 领主与附庸关系
   - 庄园经济
   - 三等级：教士、骑士、农民

4. 神圣罗马帝国（962-1806年）：
   - 奥托一世建立
   - 与教皇的权力斗争
   - investiture controversy（主教叙任权之争）

5. 诺曼人扩张：
   - 征服英格兰（1066年，黑斯廷斯战役）
   - 西西里王国
   - 基辅罗斯

四、教皇与教会
1. 教皇国建立
2. 克吕尼改革（10-11世纪）
3. 十字军东征（1095-1291年）：
   - 第一次：夺取耶路撒冷
   - 第三次：狮心王理查、腓力二世、腓特烈一世
   - 第四次：洗劫君士坦丁堡
   - 最后一次：失败告终
4. 异端运动：卡特里派、华尔登派
5. 宗教裁判所

五、中世纪文化
1. 大学的兴起：
   - 博洛尼亚大学（1088年）
   - 巴黎大学（1150年）
   - 牛津大学（1167年）
2. 经院哲学：托马斯·阿奎那《神学大全》
3. 哥特式建筑：沙特尔大教堂、巴黎圣母院
4. 骑士文学：亚瑟王传奇、特里斯丹与伊瑟
5. 但丁《神曲》：中世纪文学巅峰

【第四章 文艺复兴（约1300-1600年）】

一、意大利文艺复兴
1. 先驱：但丁、彼特拉克、薄伽丘
2. 佛罗伦萨：美第奇家族赞助
3. 艺术三杰：
   - 达·芬奇：《蒙娜丽莎》《最后的晚餐》
   - 米开朗基罗：《大卫》《西斯廷教堂天顶画》
   - 拉斐尔：《雅典学院》《西斯廷圣母》
4. 政治思想：马基雅维利《君主论》
5. 科学：伽利略望远镜观测

二、北方文艺复兴
1. 伊拉斯谟：人文主义学者
2. 印刷术：古登堡圣经（1455年）
3. 艺术家：丢勒、勃鲁盖尔
4. 英国：莎士比亚、莫尔《乌托邦》

三、地理大发现
1. 葡萄牙：
   - 亨利王子航海学校
   - 1488年迪亚士到达好望角
   - 1498年达·伽马到达印度

2. 西班牙：
   - 1492年哥伦布发现美洲
   - 1519-1522年麦哲伦环球航行

3. 影响：
   - 世界贸易网络形成
   - 殖民帝国崛起
   - 物种大交换：玉米、马铃薯、烟草传入欧亚
   - 原住民文明毁灭

一、路德宗教改革

2. 核心主张：因信称义、圣经至上

二、加尔文教改革
1. 1536年：《基督教要义》出版
2. 核心教义：预定论、天职观
3. 日内瓦：新教罗马

三、英国宗教改革
1. 亨利八世与罗马教廷决裂（1534年）
2. 圣公会成立
3. 伊丽莎白一世：折中方案

四、天主教反改革
1. 罗耀拉创建耶稣会（1540年）
2. 特伦托会议（1545-1563年）
3. 教义澄清与纪律整顿

五、宗教战争
1. 法国宗教战争（1562-1598年）：南特敕令
2. 八十年战争：荷兰独立
3. 三十年战争（1618-1648年）：威斯特伐利亚和约

【第六章 启蒙运动（约1650-1800年）】

一、科学革命
1. 哥白尼日心说（1543年）
2. 开普勒行星运动定律
3. 伽利略实验物理学
4. 牛顿《自然哲学的数学原理》（1687年）

1. 英国：
   - 洛克：《政府论》——天赋人权、社会契约

   - 休谟：经验主义哲学

2. 法国：
   - 伏尔泰：宗教宽容、言论自由
   - 孟德斯鸠：《论法的精神》——三权分立
   - 卢梭：《社会契约论》——人民主权
   - 百科全书派：狄德罗

3. 德国：
   - 康德：三大批判
   - 莱辛：戏剧理论

三、开明专制
1. 普鲁士：腓特烈大帝
2. 奥地利：玛丽亚·特蕾莎、约瑟夫二世
3. 俄国：叶卡捷琳娜大帝

【第七章 工业革命与近代社会（1760-1914年）】

一、英国工业革命
1. 前提条件：资本积累、殖民地市场、农业革命、科学传统
2. 关键发明：
   - 瓦特蒸汽机（1769年改良）
   - 珍妮纺纱机（1764年）
   - 蒸汽机车（史蒂芬森，1814年）
3. 社会影响：
   - 城市化加速
   - 阶级分化：工业资产阶级 vs 无产阶级
   - 工人运动兴起

二、法国大革命（1789-1799年）
1. 原因：财政危机、社会不公、启蒙思想影响
2. 1789年7月14日：攻占巴士底狱
3. 《人权宣言》：自由、平等、博爱
4. 君主立宪制→共和国→雅各宾专政
5. 拿破仑崛起：
   - 雾月政变（1799年）
   - 称帝（1804年）
   - 拿破仑法典
   - 滑铁卢战役（1815年）

三、19世纪欧洲
1. 维也纳体系（1815年）：保守秩序
2. 1848年革命：民族主义与自由主义
3. 意大利统一（1861年）：加里波第、加富尔
4. 德国统一（1871年）：俾斯麦"铁血政策"
5. 第二次工业革命：
   - 电力、内燃机、化学工业
   - 垄断资本主义形成

四、美国发展
1. 独立战争（1775-1783年）
2. 南北战争（1861-1865年）：废除奴隶制
3. 西进运动：边疆封闭（1890年）
4. 工业化：钢铁、铁路、石油

五、殖民帝国
1. 英国：日不落帝国
2. 法国：北非、印度支那
3. 新帝国主义（1870-1914年）：瓜分非洲、亚洲

【第八章 两次世界大战（1914-1945年）】

一、第一次世界大战（1914-1918年）
1. 导火索：萨拉热窝事件（1914年6月28日）
2. 同盟国 vs 协约国
3. 关键战役：
   - 马恩河战役（1914年）：阻止德国速胜
   - 凡尔登战役（1916年）：消耗战
   - 索姆河战役（1916年）：坦克首次使用
4. 俄国革命（1917年）：退出战争
5. 美国参战（1917年）
6. 巴黎和会（1919年）：凡尔赛条约

二、战间期
1. 凡尔赛体系
2. 经济大萧条（1929年）
3. 法西斯主义兴起：
   - 意大利：墨索里尼（1922年）
   - 德国：希特勒（1933年）
   - 日本军国主义
4. 绥靖政策：慕尼黑协定（1938年）

三、第二次世界大战（1939-1945年）
1. 爆发：1939年9月1日德国入侵波兰
2. 主要战场：
   - 欧洲：法国沦陷、不列颠空战、巴巴罗萨计划
   - 太平洋：珍珠港（1941年）、中途岛（1942年）
   - 北非：阿拉曼战役（1942年）
3. 转折点：
   - 斯大林格勒战役（1942-1943年）
   - 诺曼底登陆（1944年6月6日）
4. 结束：
   - 德国投降（1945年5月8日）
   - 原子弹投放广岛长崎（1945年8月）
   - 日本投降（1945年8月15日）
5. 后果：
   - 6000万人死亡
   - 犹太人大屠杀
   - 联合国成立
   - 核武器时代开始

【第十章 当代世界（1991年至今）】
