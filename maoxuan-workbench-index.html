📋 毛选工作台

把《毛选》的方法论变成推进工作的操作台

💡 核心原则：一次只围绕一个主目标建台账。
不要把所有事情塞进一个盘子。如果你有多个目标，拆成多个项目。

使用流程

① 在对话中告诉AI你的项目信息 — 至少提供下面最小输入单元的5项。

② AI会用毛选方法论分析 — 抓主要矛盾 + 主客分析 + 路线推演。

③ 要求输出 — 项目看板、五年计划、行动指南、HTML看板。

重要：所有输入通过对话完成，HTML只看不写。

最小输入单元（新手先跑起来）

每次至少提供这5项，AI才能做结构化分析：

1. 项目名： 2. 我想解决的问题： 3. 时间尺度：7天 / 30天 / 90天 / 1年 / 5年 4. 当前最卡的3个问题： 5. 已知的客观事实：

完整输入模板（推荐）

提供越充分，判断越准确：

1. 项目名： 2. 主目标： 3. 目标类型：晋升 / AI落地 / 组织推进 / 流程优化 / 个人转型 / 其他 4. 路线偏好：稳扎稳打 / 主动突破 / 保守防御 / 未确定 5. 时间尺度： 6. 当前阶段：起步 / 相持 / 攻坚 / 扩张 / 调整 7. 当前最卡的3个问题： 8. 敌 / 友 / 可争取力量： 9. 客观3：趋势 / 资源 / 约束 10. 主观2：判断 / 组织执行 11. 关键背景与客观事实： 12. 已做过哪些动作，效果如何： 13. 最近出现了哪些新信号、新风险、新机会： 14. 你最想先看到什么：项目看板 / 五年计划 / 思想动态 / 行动指南 / HTML

分析框架速查

抓主要矛盾

  • 先列出全部矛盾，再判断主要矛盾
  • 判断主要方面、次要方面
  • 指出哪些条件变了，矛盾会转化
  • 落到实施重点：先抓哪一点，先打哪一仗

主客分析法

成事公式：成事 = 客观3 + 主观2

  • 客观3：趋势、资源、约束
  • 主观2：判断、组织执行
  • 对每项做定性判断（1-5分）
  • 缺口必须转成补法

预测未来（三条路线）

  • 稳扎稳打线 · 主动突破线 · 保守防御线
  • 每条含：战略判断 + 方针 + 结果 + 触发条件 + 风险 + 切换信号
  • 不把预测说成确定事实

举措库（至少选3个）

  • 实事求是 · 调查研究 · 群众路线
  • 统一战线 · 试点推进 · 集中兵力 · 复盘纠偏

注意事项

  • 结论来自事实就直接说事实，来自推演就要明确是判断
  • 信息不足时列出缺失项和最值得先补的信息
  • 行动必须写清：动作、目的、验证、毛选执行标准、KPI关系
  • 不能写"加强""提高""重视"这种空话
  • 如果有旧项目要续写，先告诉AI上次结论和最新进展
